# PR #105

- Records the controlled Mainnet RLUSD Wallet Handoff reuse incident as a release blocker without exposing private operator material.
- Reads the expected payer's XRPL account `Sequence` from one validated-ledger `account_info` snapshot with endpoint failover and explicit Mainnet gate enforcement.
- Pins `Account`, `Sequence`, and a bounded `LastLedgerSequence` into every provider-created Xaman Payment request.
- Makes Wallet Handoff creation fail closed when validated signing state is missing, malformed, unvalidated, cross-network, or belongs to another account.
- Adds XRP and RLUSD tests proving a reused Wallet Handoff retains one payer sequence and one ledger expiry boundary.
- Keeps `live-mainnet-rlusd-acceptance` blocked pending reconciliation support, deployment, and a fresh controlled ceremony.
